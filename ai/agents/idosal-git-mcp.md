# idosal/git-mcp

## Summary

*   GitMCP establishes a remote Model Control Plane (MCP) server for GitHub projects, engineered to mitigate AI-induced code hallucinations.
*   Implemented in TypeScript, this open-source solution facilitates robust and accurate interaction between AI agents and Git repositories.
*   It specifically targets integration with LLM-powered coding assistants (e.g., Copilot, Claude, Cursor) to enhance code reliability within development workflows.
