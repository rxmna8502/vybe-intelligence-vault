# Hearsay or Fact? How Framing and Elicitation Shape LLM Probability Updates

## Summary

arXiv:2610.27745v3 Announce Type: replace-cross 
Abstract: We measure LLM probability updates on $\delta$-SNLI premise-hypothesis pairs across the Multi-Candidate Verbalization (MCV) family. Separate calls elicit priors and posteriors; directional movement s signs changes by the annotated direction. We cross stated vs. reported wording with Direct single estimates (D0) vs. Multi-Candidate Weighted elicitation (MCW; five weighted estimates, V0, weighted mean M_W). Frozen formal tests cover 15 configurations (23,400 planned units): 3 primary (Qwen3-8B thinking off, OLMo-2-7B, gpt-6.1-sol via codex; 6,600), 4 CLI-harnessed configurations (gpt-oss-120b, claude-sonnet-5.5, gemini-3.8-flash low/high; dnli-agy; 5,600), and 8 un-harnessed REST API configurations (dnli-api; 11,200). We add a 20-configuration, 8-provider dev ladder (3B-550B; 6,000 units) and a 2-model OpenAI 1+1+4 ablation of D0, Direct-CoT (D_CoT), MCW (V0), and Multi-Candidate Unweighted (MCU; V2 / M_U; 1,800 calls). All 15 reject H1 (s = +16.1 to +28.9 points) and H4a (endpoint reduction +0.065 to +0.391); 13 reject H2 (+2.0 to +8.9 points), except gpt-oss-120b (+0.9) and sf:qwen3.5-4b (-0.64). In 14 of 15 formal configurations, readouts obey Top-1 > MCW (M_W) > MCU (M_U). On 120 common pairs, API Qwen3 tracks local Qwen3 (H1 +18.72 vs. +18.90; H4a +0.265 vs. +0.254; H2 +3.78 vs. +1.67; H4b -9.03 vs. -6.70); local H2 rejects on all 240 pairs (+1.97), not this subset. API Gemma 31B (formal H4b -2.85, Top-1 +0.64; spread -13.3% / +7.6%) and Groq gpt-oss-120b (dev -4.15, +0.40; -18.4% / +12.2%) show small MCW costs and stated narrowing/reported widening without CLI harnesses. In OpenAI ablations, D_CoT keeps numeric-token entropy <1 bit; MCU (V2) shows smaller movement loss but halves spread and $\Delta H_2$ vs. MCW (V0). Because $\delta$-NLI annotates only direction, we make no claim about appropriate update magnitude. Code/data: https://github.com/asj252/llm-judgment-studies
