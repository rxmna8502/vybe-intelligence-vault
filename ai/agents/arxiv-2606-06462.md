# Benchmark Everything Everywhere All at Once

## Summary

arXiv:2606.06462v2 Announce Type: replace 
Abstract: Benchmarks provide standardized measures for evaluating and advancing large language models (LLMs) and multimodal LLMs (MLLMs). As models improve, existing benchmarks can approach saturation, making it harder to challenge models and distinguish among them. While reusing annotated datasets can reduce data collection and labeling effort, constructing new benchmarks remains labor-intensive, and existing agent-based approaches often target specific tasks or automate only parts of the process. To address these challenges, we introduce BenchHarness, an autonomous harness for end-to-end benchmark customization. It coordinates multiple agents and tools to analyze user requirements, search for suitable datasets, and construct validated benchmarks, with support for refinement based on model performance. To evaluate BenchHarness, we construct 16 benchmarks spanning diverse tasks and modalities. Human review and LLM-as-a-judge assessments indicate high benchmark quality, while evaluations across multiple models reveal challenging tasks and meaningful performance differences. In comparisons with source benchmarks, the generated benchmarks yield lower scores and larger performance gaps, even when the originals approach saturation. BenchHarness thus provides a reusable approach to benchmark construction, supporting informative evaluation as model capabilities and user needs evolve. Our code and benchmarks are publicly available.
