# CastClaw: A Human-in-the-Loop Autonomous Agent for Interactive Time Series Forecasting

## Summary

arXiv:2608.30976v2 Announce Type: replace 
Abstract: Practical time-series forecasting requires domain knowledge, constraints, plausibility checks, and human intervention. We present CastClaw, an interactive forecasting system centered on an autonomous forecasting loop and supported by a forecasting-oriented harness. Users create and refine tasks in natural language through command-line and Web interfaces. An internal large language model (LLM) agent reads the task and evidence, selects a permitted tool action or request for human feedback, and uses checked results to decide whether to continue, revisit an analysis, switch a candidate, or stop. The harness supplies tool integration, controlled execution, state management, historical validation, and execution limits. npm distribution connects installation and configuration to interactive execution and forecast and report export. Across five public electricity-price datasets, CastClaw achieves the lowest point-estimate MSE and MAE among 16 baselines. A Nord Pool case study illustrates its inspectable decision process, while provincial electricity-load data from North China (January--June 2026) demonstrate offline task execution.
