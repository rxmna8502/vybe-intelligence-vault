# MMGenBench: An Automated Pipeline for Evaluating LMMs from a Text-to-Image Generation Perspective

## Summary

arXiv:2411.14062v3 Announce Type: replace-cross 
Abstract: Existing benchmarks often rely on predefined questions or reference captions, limiting their flexibility for evaluating detailed descriptions on new image collections. We present MMGenBench, an automated benchmark framework for evaluating Large Multimodal Models (LMMs) from raw images without per-image questions or reference captions. The pipeline generates descriptions, reconstructs images with a frozen text-to-image model, and compares the original and reconstructed images using a frozen image encoder. It produces reusable per-image scores and inspectable reconstructions, supporting both model comparison and diagnosis of reconstructible visual information. We construct MMGenBench-Domain with 10,000 generated images and MMGenBench-Test with 1,284 images spanning 13 overlapping visual patterns. Evaluation of 68 LMMs reveals pattern-specific differences in reconstruction quality that overall scores can obscure. On 1,000 human-labeled caption pairs from six models, the default score achieves 90.00\% sample-level agreement. Factual perturbations and component analyses characterize the score's sensitivity under the evaluated pipeline, while a COCO study provides initial validation on natural photographs. MMGenBench complements existing benchmarks by linking automated comparisons to visual evidence of the information preserved in LMM descriptions. Project page: https://github.com/lerogo/MMGenBench.
