# The Transformer as a Polar State Estimator

## Summary

arXiv:2605.11007v5 Announce Type: replace 
Abstract: We show that the core components of the Transformer---attention, residual connections, normalization, and rotary encodings---arise from a single state-estimation problem. We treat each token as a noisy reading of a rotating direction on the hypersphere, taken at its own magnitude. Estimating this direction unifies the architecture: rotational dynamics give rotary encodings, robust estimation gives attention, normalization enforces the spherical geometry, and the residual connection steps toward the estimate. This reconciles normalized queries and keys with unnormalized values as opposite assumptions on whether token magnitudes are independent or share a common scale. Finally, the \emph{Polar Transformer} restores three elements standard blocks drop: rotating values alongside keys, using key magnitudes as confidence, and stepping toward the estimate rather than adding it.
