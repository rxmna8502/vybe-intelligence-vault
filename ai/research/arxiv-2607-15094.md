# AlphaWiSE: Adaptive Weight Interpolation for Continual Multimodal Representation Learning

## Summary

arXiv:2607.15094v2 Announce Type: replace-cross 
Abstract: Multimodal retrieval models align audio, images, and text in a shared embedding space, but sequential adaptation can degrade cross-modal relationships learned in earlier phases. Existing continual-learning procedures produce a single final checkpoint, so every retrieval direction shares the same stability-plasticity trade-off. We introduce AlphaWiSE, a post-hoc weight-space interpolation method that combines a sequential fine-tuning endpoint with a companion endpoint obtained with a stability-oriented continual-learning method. AlphaWiSE fits one scalar interpolation coefficient for each corresponding parameter tensor on an exemplar memory while both endpoints remain frozen. The interpolated tensors are then materialized into a single checkpoint, so the deployed model retains the architecture and inference cost of a single backbone. On continual audio-image-text retrieval, the fused model improves on the better of its two endpoints in 13 of 18 average retrieval measures and on the fixed blend of the same checkpoints in 25 of 36 measures. Its pairings achieve the strongest average audio-to-text and image-to-audio retrieval among all compared methods. Project page: https://alphawise.cvmlgroup.web.illinois.edu/
