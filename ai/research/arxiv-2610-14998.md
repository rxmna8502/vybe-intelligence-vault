# Recurrent In-Context Learning for Tabular Foundation Models

## Summary

arXiv:2610.14998v2 Announce Type: replace-cross 
Abstract: Tabular foundation models predict unlabelled rows from labelled rows in a single forward pass via in-context learning (ICL). Like language models, these architectures have scaled by stacking transformer blocks, each with its own parameters. However, this approach couples compute with model size: increasing computation requires increasing the parameter count. In this work, we investigate whether tabular ICL requires distinct parameters at every block, or simply sufficient depth. We introduce Tab-Loop, a looped tabular foundation model built on the TabICLv2 architecture. Instead of stacking unique blocks, Tab-Loop takes a small set of blocks with shared parameters and applies them repeatedly in a loop during its ICL stage. We evaluate this design against standard architectures under equal training and inference compute budgets. Our experiments show that depth, rather than unique parameters, drives performance. Across classification and regression tasks on held-out synthetic tables, the TabArena and TALENT benchmarks, Tab-Loop matches the accuracy of a standard model with three times as many ICL blocks while using roughly 60% fewer parameters. Conversely, a non-looped baseline of the same size as Tab-Loop underperforms it, even when trained on 32% more tables. This pattern holds consistently whether we vary the number of distinct blocks from one to twelve or the effective depth. Furthermore, running additional loops at inference improves predictive accuracy without retraining. Training the model with deeper loops extends the range over which these extra inference steps remain beneficial, eventually matching the released TabICLv2 on TabArena at 2.7 times the ICL compute. These results show that tabular foundation models can scale their compute independently of parameter count, pointing to test-time compute scaling as a practical path toward efficient tabular models.
