# A Unifying Framework for Robust and Efficient Inference with Unstructured Data

## Summary

arXiv:2505.00282v4 Announce Type: replace-cross 
Abstract: AI can cheaply extract structured variables from unstructured data, with alternative implementation choices potentially yielding different measures of the same concept. This creates a credibility challenge, effectively moving specification search upstream. We confront this challenge with MAR-S (Missing At Random Structured Data), a framework which adapts semiparametric missing data theory to deliver valid, efficient, robust inference with AI predictions. MAR-S anchors measurement in a transparent validation sample design, while AI scales measurement. We provide general recipes for MAR-S estimation and extend the framework to aggregated and transformed AI predictions, a common setting not addressed by existing frameworks.
