# KnowEEG: Explainable Knowledge Driven EEG Classification

## Summary

arXiv:2505.00541v3 Announce Type: replace 
Abstract: Electroencephalography (EEG) classification has shown significant promise in applications ranging from neurodegenerative disease detection to brain-computer interfaces (BCIs). Whilst deep learning methods have increasingly dominated the research landscape in recent years; these models remain largely opaque 'black boxes' with limited interpretability. In this paper, we revisit the utility of feature-based classification via a systematic pipeline designed to integrate per-electrode signal statistics with cross-brain connectivity metrics. The proposed "KnowEEG" pipeline extracts 783 per-electrode statistical features alongside between-electrode connectivity statistics, utilizing a balanced sampling strategy between high-dimensional per electrode features and connectivity. This feature-based pipeline achieves performance comparable to or exceeding state-of-the-art deep learning models across five diverse classification tasks: emotion detection, mental workload classification, eyes open/closed detection, abnormal EEG classification, and event detection. This performance is achieved without the need for Graphics Processing Unit (GPU) resources. Furthermore, the pipeline provides inherent explainability through feature importance rankings. We demonstrate via the eyes open/closed task that this explainability identifies discriminative biomarkers in the occipital region that are consistent with established neuroscience literature. These results suggest that despite significant advances in deep learning, structured feature engineering remains a high performance and interpretable method for EEG classification.
