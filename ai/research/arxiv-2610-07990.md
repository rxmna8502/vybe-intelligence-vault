# A Broader Look at Model Merging: Rethinking Implicit Regularization Induced by Task Arithmetic

## Summary

arXiv:2610.07990v2 Announce Type: replace 
Abstract: Model merging aims to build a multi-task model cheaply by combining the weights of individual task-specific models. To perform well across multiple tasks, most existing merging methods use an additional dataset to find the coefficients for the best linear combination of task-specific weight updates. However, we identify an implicit regularization in this standard practice: searching over coefficients restricts the candidate models to a subspace spanned by task-specific weight updates. In this work, we investigate whether this regularization is actually useful. Surprisingly, empirical results show that in existing benchmarks, optimizing merged-model weights without this regularization significantly boosts the performance of common merging methods across multiple architectures and domains, even in an extremely data-limited scenario where only one instance is available per class. We further investigate strategies for using the additional dataset in different settings and discuss their practical use. We show that generalization is a key factor when choosing the regularization strength. Overall, this work calls for revisiting the existing model-merging pipeline, motivating a broader exploration of the weight space and a reconsideration of the implicit regularization induced by task arithmetic.
