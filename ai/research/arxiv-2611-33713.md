# Nepali Currency Denomination Classification Using Convolutional Neural Networks (CNNs) and MobileNetV2: An Experimental Comparison

## Summary

arXiv:2611.33713v1 Announce Type: cross 
Abstract: Automated currency denomination recognition is a computer vision task with applications in cash handling, financial technology, and assistive systems. This study classifies seven Nepali currency denominations (Rs. 5, 10, 20, 50, 100, 500, and 1,000) using three configurations: a conventional convolutional neural network (CNN), MobileNetV2 with transfer learning, and MobileNetV2 with hyperparameter tuning. A compiled dataset of 16,249 images was used, comprising 10,500 training, 3,500 validation, and 2,249 independent test images. Images were resized to 128 x 128 pixels, normalized, and augmented to vary orientation, scale, illumination, and appearance. Models were evaluated using accuracy, precision, recall, F1-score, and precision-recall and ROC analysis. The hyperparameter-tuned MobileNetV2 achieved the highest validation accuracy (95\%), with precision, recall, and F1-score of 0.93, 0.91, and 0.92, but reached only 84\% accuracy on the held-out test set. MobileNetV2 with transfer learning but no additional tuning achieved 89\% test accuracy, and the conventional CNN achieved 85\%. Transfer learning therefore provided a competitive approach under the evaluated conditions, while higher validation accuracy from tuning did not yield higher test accuracy. To demonstrate practical deployment, a Flask-based web prototype using TensorFlow Lite was developed, supporting image upload and live webcam recognition with both visual and voice output. The study shows the feasibility of combining lightweight deep learning with a voice-assisted web interface for Nepali currency recognition, and highlights the need for more diverse datasets, greater robustness under uncontrolled imaging conditions, and broader real-world evaluation.
