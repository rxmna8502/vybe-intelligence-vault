# Click and Count: Multimodal Prototype Adaptation for Class-Agnostic Object Counting

## Summary

arXiv:2611.28321v2 Announce Type: replace-cross 
Abstract: We propose a multimodal, class-agnostic, density-based object counting framework that specifies the object of interest through visual exemplars, a text description, or both, within a single iterative refinement pipeline. Existing counters typically fall into two groups: methods that fuse two modalities, a hand-drawn bounding box and a text description, to specify the target object, and single-modality methods that rely on either a box exemplar or text alone. A few recent methods replace the box with a point or click. We expand a single click into a precise object mask via a frozen visual-prompt segmentation model, feeding an iterative prototype-refinement process that also fuses a text description at every refinement step. We make two contributions: first, a click-derived exemplar extraction module that removes the bounding-box requirement of prior exemplar-based counters; second, a per-step text-fusion mechanism that combines visual and textual prompts throughout refinement. Combined with text guidance, our model achieves state-of-the-art counting accuracy, outperforming prior click-based counting methods across all metrics and surpassing the box-exemplar base architecture in mean absolute error. The code is available at github.com/ameniifi/Click-and-Count.
