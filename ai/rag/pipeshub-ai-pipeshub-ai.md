# pipeshub-ai/pipeshub-ai

## Summary

*   Provides an open-source context layer for AI agents and enterprise AI search, featuring permission-aware search and cited answers across 30+ enterprise data sources (e.g., Slack, M365, Jira).
*   Offers programmatic access and integration via a Multi-Context Protocol (MCP), SDKs, and built-in agents, enabling unified information retrieval for both human users and AI systems.
*   Supports flexible deployment models, including self-hosted and cloud options, catering to private AI and RAG implementations.
