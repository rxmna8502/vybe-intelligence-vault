# Declarative Skills for AI Agents in Knowledge-Grounded Tool-Use Workflows

## Summary

arXiv:2606.06923v2 Announce Type: replace 
Abstract: We study how orchestration affects tool-using large language model (LLM) agents in customer-service workflows over an unstructured knowledge base, comparing a declarative agent that reads natural-language skill files, an imperative agent built on a state machine, and an unscaffolded baseline. The three are formalized as policy classes within one decentralized partially observable Markov decision process and evaluated on a complete design of five models, two retrieval regimes, and three agents, with paired tests. Averaged over all conditions, orchestration does not improve task success. The effect, however, depends on the quality of the agent's observation channel. Under perfect retrieval, skill files are neutral-to-negative on four of the five models; under embedding retrieval they are neutral-to-positive on four of the five. On the tasks where baseline and scaffold disagree, the declarative win rate rises from 42.4% to 62.7% (p = 0.016), and the same interaction is present for the state machine (p = 0.003). Orchestration thus substitutes for information the agent lacks rather than supplementing information it has. Since deployed systems never attain perfect retrieval, the regime in which skill files help is the realistic one. Skill files also improve write-argument accuracy in all ten conditions (p = 0.002) without improving end-to-end success, and reduce unauthorized writes only where a compliance gap exists. The state machine lowers task success on four of the five models, and its verification gate is phase routing that misclassification can bypass. Enforcing the same precondition at the tool-execution layer eliminates unauthorized writes while preserving task success.
