# Stability Regularized Cross-Validation

## Summary

arXiv:2505.06927v3 Announce Type: replace-cross 
Abstract: We study hyperparameter selection via cross-validation, motivated by settings in which the selected $k$-fold cross-validation error underestimates the selected model's test error. We propose a nested $k$-fold cross-validation scheme that minimizes a weighted sum of the standard cross-validation error and empirical hypothesis stability, with the stability weight selected by an outer cross-validation loop. We derive a generalization bound that controls test error using the cross-validation error and empirical hypothesis stability, together with correction terms common to every candidate. In a stylized ridge regression setting, we then show that whether the stability weight improves expected test-set performance depends on the signal-to-noise ratio, with the greatest improvement when the signal-to-noise ratio is small. On $13$ real-world regression datasets, the procedure reduces the average out-of-sample MSE relative to $k$-fold cross-validation by $5.6\%$ for sparse regression and by $6.8\%$ for CART. A side benefit of an outer cross-validation loop is that the selected error estimates are better calibrated than those from ordinary $k$-fold cross-validation: the error estimate moves from 12.3\% below the selected test-set MSE to 5.8\% above it for sparse regression and from 10.3\% below to 0.2\% above it for CART.
