# Welcome - GraphRAG

## Summary

*   GraphRAG is a hierarchical RAG framework that constructs a knowledge graph from an input corpus, performs hierarchical community clustering (e.g., Leiden technique), and generates bottom-up community summaries.
*   The indexing process involves slicing text into `TextUnits`, extracting entities, relationships, and claims, followed by graph-based community detection and summarization.
*   Query-time augmentation leverages these structures through distinct modes: `Global Search` for holistic reasoning using community summaries, `Local Search` for entity-specific fan-out, and `DRIFT Search` combining entity fan-out with community context.
