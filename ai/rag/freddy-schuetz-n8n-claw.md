## Summary

*   n8n-based autonomous AI agent framework, inspired by OpenClaw, enabling workflow-driven agent orchestration.
*   Integrates adaptive RAG for contextual memory, implements skills via Model Context Protocol (MCP) templates, and supports hierarchical expert/sub-agent delegation with proactive task management.
*   Self-hostable with a single setup script, leveraging SearXNG for search capabilities and Supabase for backend services.
