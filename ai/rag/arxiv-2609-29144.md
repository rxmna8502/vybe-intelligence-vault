# Task-Specific Agent Memory For Continual Learning

## Summary

arXiv:2609.29144v2 Announce Type: replace 
Abstract: Language-model agents can learn continually by storing useful instructions in memory and reusing them as new tasks arrive, without changing model weights. This requires both learning from new feedback and retaining earlier gains. However, an instruction learned from one task family can hurt other families when the agent uses the same memory for every task. We introduce task-specific agent memory: proposed skills are checked with execution tests, stored by task family, and retrieved for tasks in that family. We evaluate this design on a 12-round code-repair benchmark with recurring task families, tracking performance throughout learning. Holding proposals, acceptance decisions, and task completions fixed, task-specific retrieval raises average performance from 0.713 to 0.816. Across 27 paired randomized-order streams with Qwen3-Coder-Next, it improves average performance by 0.063 over global memory and by 0.055 over an agent that never updates its memory, accumulating 63 skills with no observed harmful acceptance. Capacity-matched retrieval and cumulative one-shot controls further support the value of task-specific retrieval and sequential skill accumulation. Our contribution is to identify cross-family interference and show how task-specific agent memory supports continual learning through skill accumulation and retention.
