# NSFL: A Post-Training Neuro-Symbolic Fuzzy Logic Framework for Boolean Operators in Neural Embeddings

## Summary

arXiv:2604.10604v2 Announce Type: replace-cross 
Abstract: Standard dense retrievers have no native mechanism for multi-atom logical constraints. We introduce Neuro-Symbolic Fuzzy Logic (NSFL), a training-free framework that brings fuzzy-logical structure to neural embedding spaces through a first-order finite-difference treatment of similarity. NSFL anchors logical operations on zero-order atomic scores while steering with Neuro-Symbolic Deltas (NS-Delta) -- the marginal semantic contributions induced by contextual fusion -- preserving atomic meaning while capturing contextual dependence, and avoiding the representation collapse and manifold escape endemic to geometric baselines. For latency-constrained deployment, Spherical Query Optimization (SQO) uses Riemannian optimization to project logical formulas into manifold-stable query vectors. Across six encoder configurations and two modalities, NSFL yields mAP@100 improvements up to +81% on QUEST and +70% on a COCO-derived text-to-image benchmark, and provides an additive +19% average gain on an encoder already fine-tuned for logical retrieval. On NevIR, where absolute accuracies are directly interpretable, NSFL doubles pairwise accuracy -- NevIR's both-correct criterion -- from 0.256 to 0.508. The decomposition is exact and general; the operators built on it are engineering realizations rather than a closed algebra, and we state that boundary precisely. Code is available at https://github.com/vladiaidev-lab/NSFL
