# vstorm-co/full-stack-ai-agent-template

## Summary

*   Full-stack AI application generator leveraging FastAPI (Python) for backend services and Next.js (React/TypeScript) for the frontend, inherently supporting RAG, streaming, and authentication.
*   Integrates multiple AI agent frameworks including CrewAI, LangChain, and LangGraph, enhanced by Pydantic-AI for robust data modeling and agent interaction.
*   Provides a Dockerized deployment environment with PostgreSQL persistence, WebSocket support for real-time interactions, and 20+ pre-configured integrations for rapid development.
