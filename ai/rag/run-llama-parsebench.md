# run-llama/ParseBench

## Summary

*   `ParseBench` is a Python-based benchmark suite designed for evaluating AI agent performance in document parsing.
*   It assesses efficacy across critical document AI tasks, including OCR, PDF parsing, and table extraction, relevant for LLMs and Vision-Language Models.
*   The framework provides an evaluation methodology for document understanding agents, including those leveraging LlamaIndex, against diverse parsing challenges.
