# Multi-Modal, Multi-Temporal Geospatial Foundation Models Improve Global Above-Ground Biomass Estimation

## Summary

arXiv:2608.04792v2 Announce Type: replace 
Abstract: Accurate estimation of above-ground biomass (AGB) from satellite imagery is essential for the large-scale monitoring of carbon stocks, yet it remains a challenging regression task at global scale. Geospatial Foundation Models (GFMs) have recently emerged as a promising machine learning paradigm to derive general-purpose representations from Earth observation (EO) data, but their utility for quantitative regression tasks like biomass estimation remains largely unexplored, as most benchmarks focus on classification and segmentation. Here, we benchmark 13 GFMs for above-ground biomass estimation, specifically GEDI L4A biomass values. We compare them against a fully supervised state-of-the-art (SOTA) baseline trained on A Global-scale Biomass Dataset (AGBD), a machine learning-ready benchmark spanning diverse biomes and geographies. Most of the GFMs evaluated substantially underperform with respect to the supervised baseline, whether frozen or fine-tuned; only TESSERA and AlphaEarth Foundations (AEF) features with certain prediction heads yield a better performance. Our SOTA model trained on AEF embeddings and selected raw EO features achieves the best overall result (RMSE of 50.79 Mg/ha vs. 53.73 Mg/ha on AGBD features). This feature combination also generalizes better than AGBD features: it reduces RMSE by up to 25% in selected regions excluded from training, and, trained on single-year data alone, it outperforms the model trained on multi-year AGBD features. With labels from only 11 regions around the world, the AEF-based model also performs on par with the globally calibrated ESA CCI biomass product on independent reference plots. These findings indicate that GFM features can be highly informative for biomass estimation, when the underlying model is trained on rich multi-modal data.
