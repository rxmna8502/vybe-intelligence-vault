# Improving Early Detection of Scientifically Interesting Radio Sources Using Enhanced Isolation Forest

## Summary

arXiv:2611.21674v1 Announce Type: cross 
Abstract: The rapid growth of radio astronomical surveys has created a major challenge in identifying scientifically interesting sources from large populations of observed objects. This study investigates whether enhanced Isolation Forest (iForest) methods can improve the early detection and ranking of scientifically interesting radio sources. Four iForest variants, Standard Enhanced, Pooled Gain, Kurtosis-based, and Hypervolume, are evaluated using 1,031 extended radio sources from the MeerKAT Galaxy Cluster Legacy Survey (MGCLS). Each source is represented by a 52-dimensional feature set derived using Bootstrap Your Own Latent (BYOL) self-supervised learning and principal component analysis (PCA), while expert scientific-interest ratings are used to define the ground-truth labels. The methods are evaluated using Average Precision (AP), receiver operating characteristic area under the curve (ROC AUC), Precision@10, Precision@50, and cumulative anomaly detection. Pooled Gain achieves the highest Average Precision (AP = 0.201) and the strongest early-stage ranking performance (P@10 = 0.600), identifying six expert-validated anomalies among the ten highest-ranked sources. Standard Enhanced and Kurtosis-based achieve the highest ROC AUC (0.677), while the AUC values of the four variants range from 0.653 to 0.677. These results indicate that feature-aware isolation strategies can improve the prioritization of scientifically interesting sources at the top of the ranked list, although overall discrimination remains comparable across the evaluated variants. The findings support the use of enhanced Isolation Forest methods as an initial ranking mechanism within human-in-the-loop systems for large-scale radio astronomical surveys.
