# 🔎 Build a RAG Agent with Azure AI Search | Agent Academy

## Summary

*   Azure AI Search is configured with integrated vectorization, leveraging an Azure OpenAI `text-embedding-ada-002` model deployment to transform unstructured documents (e.g., PDFs) into semantic vectors for meaning-based retrieval.
*   A vector index is populated by ingesting documents from Azure Blob Storage via the Azure AI Search "Import data (new)" wizard, which automates chunking, vectorization, and indexing for RAG scenarios.
*   A Microsoft Copilot Studio agent is integrated with Azure AI Search as a *connector tool* (specifically the `Semantic Hybrid Search` action), enabling the agent to perform vector-enhanced RAG for grounding responses in enterprise documents with explicit citations, guided by instruction engineering.
