# MCP Stack Map

## Overview
Model Context Protocol for exposing data and tools safely to LLMs.

## Core Concepts
MCP client-server architecture, JSON-RPC, tools, resources, prompts.

## Key Tools and Frameworks
Claude Desktop, MCP Python SDK, MCP TypeScript SDK.
