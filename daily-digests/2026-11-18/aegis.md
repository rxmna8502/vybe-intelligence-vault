## Summary
AEGIS is an AI-native defense platform that acts as a security gateway for LLM applications and agentic systems, protecting against prompt injection, jailbreaks, data exfiltration, tool/MCP abuse, and supply-chain tampering with tamper-evident audit trails.

## Key Features
- Defense-in-depth architecture with input/output defense layers, policy engine, and agent gate
- CEL-based policy evaluation for flexible, dynamic security rules
- Tamper-evident audit trails with Ed25519-signed receipts
- Continuous red-team adversarial testing for ongoing security validation
- Provider-agnostic model routing supporting multiple LLM providers

## Why It Matters for RAG Builders
AEGIS provides critical security infrastructure for RAG and AI agent systems, ensuring robust protection against adversarial attacks and compliance with tamper-evident logging standards.
