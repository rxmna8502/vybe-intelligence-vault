## Summary
A real-time trading analytics platform that ingests broker data (FXCM/Binance) into a UnifiedDataStore (UDS), computes Smart Money Concepts (SMC) analytics, and serves live WebSocket charts with a read-only API for external clients like AI agents or dashboards.

## Key Features
- Hard data invariants with a single UnifiedDataStore (UDS) as the write-center
- Real-time SMC analytics (BOS, CHoCH, order blocks, FVG, liquidity) computed in-process
- Read-only HTTP/WebSocket API for external clients (AI agents, dashboards, notebooks)
- Dual-venv architecture for broker isolation and production-grade reliability
- Comprehensive documentation with 90+ ADRs and runbooks for deployment and recovery

## Why It Matters for RAG Builders
Provides a robust, real-time data pipeline and analytics engine for AI agents to consume market structure data without fabricating trading signals, enabling reliable RAG applications for financial analysis.
