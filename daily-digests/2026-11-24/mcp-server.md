## Summary
Extentos MCP Server enables AI coding agents to integrate smart-glasses capabilities (camera capture, voice triggers, live transcription, audio playback) into Android and iOS apps via the Model Context Protocol (MCP). It provides deterministic tools for discovery, scaffolding, validation, simulation, and production deployment.

## Key Features
- Deterministic MCP tools for smart-glasses integration (discovery, scaffolding, validation, simulation)
- Browser-based simulator for end-to-end testing without hardware dependencies
- Multi-platform support (Android, iOS) with Meta smart glasses compatibility
- Automated scaffolding of connection modules and configuration files
- Production checklist and credential guidance for real-world deployment

## Why It Matters for RAG Builders
