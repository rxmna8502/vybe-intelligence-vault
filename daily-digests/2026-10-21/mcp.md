## Summary
OutageDeck MCP provides AI coding agents with real-time status checks, incident timelines, and independent uptime history for 172 cloud and SaaS vendors. It helps agents answer 'is it us or them?' before debugging by querying official provider status feeds.

## Key Features
- Real-time status checks for 172 cloud and SaaS vendors from official feeds
- Incident discovery and complete vendor update timelines with citable sources
- Independent 7–90 day uptime history and cross-vendor outage reports
- Free, keyless public tools for live status and incident queries
- Account-authenticated custom provider and alert management

## Why It Matters for RAG Builders
It enables AI agents to quickly verify if outages are vendor-side or user-side, reducing debugging time and improving reliability assessments.
