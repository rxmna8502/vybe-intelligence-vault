## Summary
AgentHouse Skills is an open-source collection of reusable, structured skills for AI agents that perform professional tasks like sales qualification, innovation capacity building, and role profiling. Each skill includes instructions, templates, and examples for consistent agent execution.

## Key Features
- Pre-built, modular skills for AI agents with structured instructions and examples
- Supports CLI-based installation and ZIP-based deployment for compatibility with SKILL.md-based agents
- Automated release pipeline with versioned skill packages and checksums
- Covers diverse domains like sales, governance, innovation, and organization design
- Designed for interoperability with tools like Claude Code, Cursor, and Gemini CLI
