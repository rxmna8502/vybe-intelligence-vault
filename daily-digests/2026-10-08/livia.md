## Summary
Livia is a self-hosted AI executive assistant that integrates with Gmail and Google Calendar to automate scheduling, correspondence, research, and bookings. It operates as a white-label service with a web-based setup wizard for configuration.

## Key Features
- Web-based setup wizard for zero-code configuration
- Gmail and Google Calendar integration for scheduling and correspondence
- Anthropic API for AI-driven message drafting and reasoning
- Lightweight CRM for contact management
- RESTful API endpoints for agent interaction and task execution
