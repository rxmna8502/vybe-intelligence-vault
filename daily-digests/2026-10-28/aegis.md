## Summary
Aegis is an adaptive AI harness for IT operations that automates problem-solving by selecting the smallest sufficient execution shape (e.g., deterministic replay, direct reasoning, specialist agents) based on plain English input. ## Key Features

- Controlled operational memory with provenance tracking and gated promotion
- Built-in security model with adversarial probes (T1-T10) and PII/credential scanning
- Verified outcomes with Jira-ready notes and zero-trust execution
